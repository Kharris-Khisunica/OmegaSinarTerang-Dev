Kartu Ringkas Operator — OmegaSinarTerang

Tempel di dekat komputer kasir. Versi aplikasi v1.0 · Oktober 2026 (revisi 2) · Panduan lengkap: Panduan Pengguna OmegaSinarTerang.

Pola dasar

  • Menu → Entri → isi kepala → Entri (baris) → Simpan baris → Simpan dokumen.
  • Klik baris di daftar (tanda ▶) → View Detail untuk Cetak / Ubah / VOID.
  • Qty = angka + Satuan (otomatis DUS). Isi = isi per satuan.
  • SISA STOK “13 dus +” = 13 dus lebih sedikit. Stok boleh minus.

Pesanan dikirim

  1. Order Penjualan → Entri: Pelanggan, Salesman (PJ), barang → Simpan.
  2. Klik order → Jadikan Faktur → cek harga & Termin (hari) → Simpan.
  3. Faktur → Cetak → Cetak.
  4. Pilih faktur → Buat Surat Jalan: Tanggal Kirim, Salesman, Kendaraan → cetak dari menu Surat Jalan.
  5. Besoknya: Surat Jalan → saring Belum Terkirim → Ubah Status Kirim (tanpa izin).
  6. Order tidak jadi: detail order → Batalkan SO + alasan.

Pembeli di toko

  1. Faktur Penjualan → Entri (Saluran Toko).
  2. Pelanggan (atau Baru), Salesman, Termin.
  3. Baris: Produk, Satuan, Harga @ (lihat RIWAYAT HARGA), Qty.
  4. Simpan → cetak nota.

Barang datang dari supplier

  1. Faktur Pembelian → Entri: Supplier (pilih dari kode), No. Faktur Supplier (boleh kosong).
  2. Tgl Terima Barang = tanggal barang masuk; Tgl Faktur Supplier = tanggal di nota; Termin.
  3. Baris barang; bonus pakai tombol Bonus (harga 0).
  4. Diskon supplier → kotak Diskon Faktur (rupiah) → Simpan.

Pembayaran

  1. Penerimaan Kas (dari pelanggan) / Pengeluaran Kas (ke supplier) → Entri.
  2. Entri baris → klik faktur → pilih akun kas/bank + nominal.
  3. Lunas dengan selisih kecil? centang Tandai Lunas.
  4. Simpan → Konfirmasi Pembayaran.

Biaya & kas

  • Biaya Operasional → Entri → baris tab Biaya atau Kasbon. Boleh mundur 7 hari.
  • Isi ulang Kas Kecil Rp 1.000.000 / setor Kas Toko ke Kas Besar: Pindah Buku Kas.
  • Karyawan setor kasbon: Pelunasan Kasbon → klik nama pekerja → Nominal Setoran.

Retur, rusak, titipan

  • Barang rusak di toko: Mutasi Gudang → Transfer, Toko → Barang Rusak. Qty + satuan.
  • Retur dari pelanggan: Retur Penjualan → ketik Faktur Asal + Tab → centang, Qty Retur → Kurangi Piutang / Tunai. Barang masuk Barang Rusak. Salah? Detail → Ubah / VOID.
  • Retur ke supplier: Retur Pembelian → Supplier → centang barang → Nilai Retur / Satuan sesuai kesepakatan.
  • Tukar barang: Retur Pembelian + Faktur Pembelian baru.
  • Titipan: Mutasi Gudang → Titipan Pelanggan → Pelanggan → Faktur → pilih baris faktur → Qty + satuan.

Catatan: Insert/F2/Delete berlaku di Faktur Penjualan & Pembelian, Order, Mutasi, Biaya Operasional. Ctrl+H/Ctrl+D sudah tidak dipakai.

Kalau salah input

KeadaanLakukan
Belum disimpanPerbaiki langsung / Keluar.
Tersimpan, belum dicetak, ≤ 2 hariDetail → Ubah → Simpan (nomor tetap, “Revisi N”).
Sudah dicetak, ≤ 2 hariDetail → Batal Cetak → Diperbaiki + Alasan → Lanjutkan → perbaiki → Simpan → tunggu Supervisor → cetak ulang.
Lewat 2 hariVOID (Kode Alasan + Catatan Alasan) → buat faktur baru. Sistem tidak macet — memang begitu aturannya.
Ditandai BermasalahBaris merah di daftar. Baca catatan merah di Detail → perbaiki → kabari Supervisor.

Menunggu Persetujuan

  • Muncul untuk: VOID dokumen apa pun (Operator), Batal Cetak, harga di bawah harga pokok, kas besar keluar, Barang Rusak → Toko.
  • Biarkan jendela terbuka, kabari Supervisor. Disetujui → tersimpan sendiri.
  • Berlaku 15 menit. Ditolak / habis → perbaiki, ulangi.
